# ML Journey

PWA для обучения по плану `ml-plan-aspirantura-1.2.1.md` — вход в ИИ и машинное обучение
для аспирантуры по специальности 1.2.1.

Приложение делает три вещи, ради которых и собиралось:

1. **Даёт материал по теме** — подобранные ссылки на первоисточники плана (хендбук Яндекса,
   MML, 3Blue1Brown, документация NumPy и так далее) плюс чек-лист «что должно остаться в голове».
2. **Отмеряет время на изучение теории** — обратный таймер на плановую длительность темы.
   Пока он не отработает, практика закрыта. Время учитывается по временным меткам, поэтому
   переживает перезагрузку страницы, закрытие вкладки и переход в фон.
3. **Даёт практику и тест** — конкретное задание с шагами и критериями готовности,
   а после него тест с разбором каждого ответа. Порог сдачи — 80%.

## Запуск

```sh
./serve.sh          # http://localhost:8080
./serve.sh 3000     # другой порт
```

Открой ссылку в браузере. На телефоне — «Добавить на экран «Домой»»: приложение
установится и будет работать офлайн.

Можно открыть `index.html` и двойным кликом, но тогда не будет ни офлайн-режима,
ни установки, а часть браузеров запретит сохранять прогресс. Для реальной учёбы
используй сервер.

Никакой сборки, npm и зависимостей: чистые HTML, CSS и JS.

«Каркас» означает: тема, сроки, материалы и оценка времени заведены, таймер работает,
но практическое задание и тест не написаны. Наполняются по мере подхода к фазе.

## Как это работает

Тема проходится в три шага:

```
Теория  →  Практика  →  Тест
таймер     задание       вопросы
чек-лист   с шагами      с разбором
```

- **Практика** открывается, когда таймер теории отработал плановое время.
  Если тема уже знакома — кнопка «Я уже знаю тему» открывает её сразу.
- **Тест** открывается после отметки «практика выполнена». Есть и ручное открытие:
  блокировки здесь — это опора, а не решётка.
- **Тема считается закрытой**, когда пройден чек-лист теории, отмечена практика
  и тест сдан на 80% и выше. Варианты ответов перемешиваются при каждой попытке.

Прогресс, заметки и результаты хранятся в `localStorage` этого браузера.
В «Ещё → Резервная копия» есть выгрузка и загрузка JSON — делай копию раз в месяц,
очистка данных сайта удалит всё.

## Как добавить тему

Тема — обычный объект в одном из файлов `js/data-*.js`:

```js
{
  id: 'p1-metrics',                  // уникальный, не меняй после начала занятий:
                                     // по нему привязан сохранённый прогресс
  title: 'Метрики качества',
  summary: 'Одна фраза о том, зачем эта тема.',
  theoryMinutes: 150,                // на столько заводится обратный таймер
  practiceMinutes: 120,
  resources: [
    { title: 'Название материала',
      url: 'https://...',            // необязательно: без url будет просто текст
      source: 'домен или «книга»',
      note: 'зачем это читать' }
  ],
  checklist: [                       // «что должно остаться в голове»
    'Понимаю, почему accuracy бесполезна на несбалансированных классах'
  ],
  practice: {
    title: 'Название задания',
    description: 'Контекст: что и где делать.',
    steps: ['Шаг 1', 'Шаг 2'],
    acceptance: ['Как понять, что сделано правильно']
  },
  quiz: [
    { q: 'Текст вопроса',
      options: ['Вариант 1', 'Вариант 2', 'Вариант 3', 'Вариант 4'],
      correct: [0],                  // индексы верных вариантов;
                                     // если их несколько — допиши в текст вопроса
                                     // «(несколько ответов)», приложение это не дорисует
      explain: 'Почему так, и почему остальные варианты неверны.' }
  ]
}
```

Убери `stub: true`, когда тема наполнена — исчезнет пометка «каркас».

После правки файлов подними `CACHE_VERSION` в `sw.js`, иначе установленное
приложение продолжит отдавать старую копию из кэша.

## Про ссылки

168 ссылок на материалы ведут на первоисточники, названные в плане.
Часть из них проверить автоматически не удалось — хосты `stanford.edu`,
`coursera.org`, `vak.minobrnauki.gov.ru` и `semanticscholar.org` не отвечали
на автоматические запросы. Это не значит, что ссылки битые, но если какая-то
не открылась — ищи материал по названию, оно указано полностью.

Для двух источников ссылка не приводится намеренно: **The Matrix Cookbook**
и **Deep Learning School (МФТИ)** живут на меняющихся зеркалах, и битая ссылка
хуже её отсутствия — они указаны по названию.
